# 👨‍💻 About Me

I'm a **Software Engineer first, Data Engineer by depth.**

I build end-to-end systems — from backend APIs and full-stack applications to large-scale data platforms, distributed processing pipelines, cloud-native architectures, and secure production deployments.

My interests sit at the intersection of **Software Engineering, Data Engineering, Security, and AI Systems**.

I care less about demos and more about:

- ⚙️ How systems fail
- 📈 How systems scale
- 🔍 How trust is measured
- 🔐 How security holds under pressure
